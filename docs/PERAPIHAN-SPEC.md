Payment: ganti istilah paket menjadi akses di seluruh copy tampilan; QRIS langsung tanpa email tetap. Harga minimal Rp1.000. Pemilik menerima notifikasi pembayaran berupa nama pembeli clickable tg://user?id, nama akses, harga saja. Pesan sukses pembeli dengan tombol Masuk Channel/Grup sesuai jenis target. History snapshot nama/harga lama dan tombol hanya jika belum digunakan. Welcome nama pembeli plain; custom teks/foto tetap.
Admin Payment: owner tambah/cabut melalui ID. Admin hanya nama/deskripsi/foto akses, sambutan teks/foto (preview+konfirmasi), broadcast. Tidak ada transaksi, harga/target, akun, tambah/hapus/aktifkan akses, pengurutan, kelola admin. Tambah admin ditolak jika belum /start; kirim notifikasi sebelum grant dan jangan grant jika pengiriman gagal. Owner tambah ulang setelah /start. Hapus admin tetap mencabut, notif best effort.
Owner: dapat mengurutkan akses via Naik/Turun dengan label nama. Broadcast seluruh pengguna /start; preview dan konfirmasi; stop hanya pembuat, hasil hanya pembuat (sent,failed,remaining jika stopped).
