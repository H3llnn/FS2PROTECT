# Zeisss SubGate Implementation Plan

> Execute inline, task by task using superpowers:executing-plans.

**Goal:** Implement the approved multi-bot Telegram file-sharing service.
**Architecture:** Telegram Bot API clients supervised in one asyncio process;
Telethon validates API credentials per deployment. SQLite persists isolated
settings, links, permissions and deletion jobs. Fernet encrypts credentials.
**Tech Stack:** Python 3.12+, Telethon 1.45, aiohttp, cryptography, dotenv, unittest.
**Spec:** docs/spec.md

## Global Constraints
- Only configured master owner can grant/revoke; only child owner edits settings.
- Max four required chats; default protection off; default deletion 1800 seconds.
- Regrant does not resume revoked bots; redeploy preserves ownership and data.
- No credentials in source/logs; no hard-coded third-party admins.

## Review Focus
- Concurrent redeploy/revoke cannot leave an unauthorized child running.
- Invalid membership result must never release files.
- Partial batch delivery and interrupted deletion retain durable jobs.
- Token rotation must not change ownership or lose links.
- Callback authorization must match message authorization.
